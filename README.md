# PowerShell Port Scanner

Parallel TCP port scanner in pure PowerShell.

**Skills:** PowerShell, background jobs, TCP sockets, network discovery

**Value:** Checks firewall rules and exposed services on locked-down hosts where nmap cannot be installed.

Run: `.\port-scanner.ps1 -target 192.168.1.10 -startPort 1 -endPort 100`

> Scan only systems you own or are authorized to test.
